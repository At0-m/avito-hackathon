# Фронтенд Avito Recap City

Интерфейс показывает персональные «Итоги года» как интерактивный город. Вертикали становятся районами, категории — улицами, а активность влияет на застройку.

## Запуск

```bash
npm ci
npm run dev
```

Приложение откроется на `http://localhost:5173`.

| Команда | Назначение |
|---|---|
| `npm run dev` | сервер разработки Vite |
| `npm run test` | тесты API-слоя |
| `npm run lint` | ESLint |
| `npm run build` | проверка типов и production-сборка |
| `npm run check` | тесты, lint и build |
| `npm run format` | форматирование Prettier |

Для полного сценария удобнее запускать проект из корня:

```bash
docker compose up -d --build
```

## Пользовательский путь

1. `/` — выбор тестового профиля и года.
2. `/generate/:profileId/:year` — экран асинхронной генерации с реальными этапами.
3. `/recap/:recapId` — последовательность карточек и итоговый город.
4. `/share/:recapId` — безопасная публичная карточка.

Генерация отслеживается через SSE. Если соединение обрывается, frontend автоматически переходит на polling.

## Основные решения

### Город

Город рисуется на `<canvas>`, а не набором DOM-элементов. Раскладка и высота зданий воспроизводимы: seed выводится из `activity_hash`, поэтому один и тот же recap выглядит одинаково.

### Данные

Бэкенд остаётся источником бизнес-данных. Адаптер фронтенда преобразует API DTO в модель экранов, но не пересчитывает метрики, роль или достижения.

### Приватность

Публичная карточка загружается отдельным запросом `/share`. Личные объяснения и внутренние метрики в неё не попадают.

### Объяснения

Роль, стиль и достижения можно раскрыть через путь `/explanation`. Запрос выполняется только при открытии соответствующего блока.

## Структура

```text
src/
├── app/                  роутер и оболочка приложения
├── pages/
│   ├── profiles/         выбор профиля
│   ├── generating/       ожидание генерации
│   ├── recap/            итоговые карточки и город
│   └── share/            публичная карточка
├── widgets/share-card/   компоненты публикации
├── entities/city/        раскладка и Canvas-рендер
└── shared/
    ├── api/              DTO, клиент, adapter, SSE и polling
    ├── lib/              палитра, random и склонения
    ├── theme/            дизайн-токены
    └── types/            модель экранов
```

## Ограничения

- используются тестовые профили и заранее подготовленные события;
- CTA не ведут в реальный продукт Авито;
- текущий экран акцентирует главный район, а несколько полноценных вертикалей остаются следующим продуктовым шагом.
