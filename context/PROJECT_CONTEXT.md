# Контекст проекта

Обновлено: 2026-08-30.

## Цель

Avito Recap City превращает активность тестового профиля за год в персональный интерактивный город: метрики, роль, стиль, достижения, объяснения и безопасную карточку для публикации.

## Ограничения

- фронтенд: React и TypeScript;
- бэкенд: Go;
- общий репозиторий и запуск через Docker Compose;
- PostgreSQL хранит профили, состояние и готовые snapshots;
- ClickHouse хранит события активности;
- правила расчёта воспроизводимы;
- в публичную карточку не попадают переписки, точные покупки и данные других пользователей.

## Хакатонный MVP

На хакатоне были реализованы основной пользовательский путь, детерминированная генерация, Canvas-город, PostgreSQL/ClickHouse, Mistral с шаблонным fallback, тесты, CI и Docker Compose.

## Доработка после хакатона

После MVP появились:

- асинхронный `POST /recaps`;
- отдельный worker;
- retry, lease и heartbeat;
- transactional outbox и consumer inbox;
- Redpanda и DLQ;
- SSE с polling fallback;
- конкурентные и fault-тесты;
- набор воспроизводимых benchmark-сценариев.

Эта доработка не относится к функционалу, сделанному в сроки хакатона.

## Основные решения

- frontend получает готовые бизнес-данные и не пересчитывает метрики;
- готовый recap хранится как неизменяемый snapshot;
- Mistral работает только с разрешёнными фактами, при ошибке используется шаблон;
- PostgreSQL остаётся источником состояния;
- Redpanda используется как транспорт команд, а режим `hybrid` страхует локальный запуск через очередь PostgreSQL.
