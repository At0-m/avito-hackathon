# Результаты нагрузочных тестов

В этом каталоге нет заранее подготовленных показателей.

Запуск из корня проекта:

```bash
make bench-smoke
make bench-paths
make bench-matrix
make bench-faults
```

Каждый запуск создаёт отдельную папку с JSON-отчётами, Markdown-сводкой, сведениями об окружении и логами сервисов. При сравнении архитектур нужно хранить весь набор файлов, а не только лучший показатель задержки.
